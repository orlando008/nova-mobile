# Navigation & Menus

Twenty white icons on transparent backgrounds, designed to be tinted by the cart. Each individual PNG is 96 × 96 pixels. Copy the icons you need from `icons/` into your cart's assets and list them in `game.json`.

![Navigation and Menus icon preview with a 24-pixel size check](preview.png)

The transparent [sprite sheet](sheet.png) is 480 × 384 pixels. Each cell is 96 × 96 pixels with no spacing between cells. The cell names below also match the individual PNG filenames.

| Row | Column 1 | Column 2 | Column 3 | Column 4 | Column 5 |
|---|---|---|---|---|---|
| 1 | up | right | down | left | back |
| 2 | play | pause | stop | replay | home |
| 3 | plus | minus | close | menu | settings |
| 4 | sound-on | sound-off | skip-back | skip-forward | fullscreen |

Original artwork for NOVA Mobile.
